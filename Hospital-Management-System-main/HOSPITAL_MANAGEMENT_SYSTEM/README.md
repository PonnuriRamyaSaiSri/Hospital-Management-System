# MediCare Plus - Hospital Management System

A front-end web application for a modern healthcare clinic, "MediCare Plus". This project provides a user-friendly interface for patients to access medical services, book appointments, view doctor profiles, and manage health records online.

## Features

- **Home Page (`index.html`)**: A welcoming landing page featuring the clinic's core services, quick links, and a modern UI.
- **Doctors Profile (`doc.html`)**: View a list of highly qualified and experienced medical professionals.
- **Book Appointment (`bapp.html`)**: An easy-to-use booking system for scheduling appointments online.
- **Patient Dashboard (`pd.html`)**: A comprehensive portal to track health journeys and medical records.
- **Pharmacy (`pharmacy.html`)**: Access an online pharmacy to get prescribed medications delivered.
- **Payment (`payment.html`)**: A secure interface for processing payments.

## Technologies Used

- **HTML5**: For semantic structuring of the web pages.
- **CSS3 (`styles.css`)**: For custom, responsive, and modern styling. Includes modern layouts (Flexbox/Grid), animations, and custom typography.
- **JavaScript (`script.js`)**: For adding interactivity and handling client-side logic.

## Getting Started

1. Clone or download the repository to your local machine.
2. Open the project folder (`HOSPITAL_MANAGEMENT_SYSTEM`).
3. Double-click on `index.html` to run the application in your default web browser.
